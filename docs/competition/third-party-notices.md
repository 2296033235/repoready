## 编制说明

本清单按官方参考表的八个字段编制：资源名称及类型、版本/来源、许可证/授权类型、使用/开放方式、关键义务/限制、团队自主修改或开发内容、合规状态。资源类型按"开源软件、模型、数据集、框架、组件、工具、素材或第三方服务"归类；合规状态按"已核验 / 待核验 / 不适用"填写。

本作品的一个结构性优势是**运行时零第三方 Python 依赖**，因此清单短、义务清晰、可核验项多。这不是偶然——选型阶段就把"减少依赖"当作作品主张的一部分：一个专治"装不上"的工具，自己越少依赖，越少失败点。
